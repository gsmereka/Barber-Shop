# Barber Shop – Aplicativo de Agendamento de Barbearia

Bem-vindo ao repositório final do projeto **Barber Shop**, uma aplicação web desenvolvida para facilitar o agendamento de serviços em barbearias. Este projeto foi criado como parte do bootcamp **Decola Tech 2025**, promovido pela DIO em parceria com a Avanade, com foco em tecnologias como Java Spring Boot e Angular ([dio.me](https://www.dio.me/en/bootcamp/decola-tech-2025?utm_source=chatgpt.com)).

## 🚀 Acesse o aplicativo

Você pode testar a aplicação diretamente no navegador através do seguinte link:

👉 [Barber Shop](https://gsmereka.github.io/Barber-Shop-UI/)

## 🧱 Tecnologias utilizadas

- **Frontend:** Angular
- **Backend:** Java com Spring Boot
- **Banco de dados:** PostgreSQL
